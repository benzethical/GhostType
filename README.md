# GhostType <img align="center" width="50px" src="https://cdn3d.iconscout.com/3d/premium/thumb/keyboard-typing-3d-icon-png-download-14895998.png">
GhostType silently types so you don't have to. Fast, customizable, and built<br> to automate repetitive keystrokes with precision. Press a key, watch the ghost do the work.<br>Made in Python <img align="center" width="20px" src="https://static.vecteezy.com/system/resources/previews/012/697/295/non_2x/3d-python-programming-language-logo-free-png.png">

# Versions
There are currently 2 versions for GhostType!<br>`Python [Terminal Based]` `.Exe [Executable]`

# How to install & use?
This is a guide on how to use the tool.<br>
### <img align="center" width="20px" src="https://static.vecteezy.com/system/resources/previews/012/697/295/non_2x/3d-python-programming-language-logo-free-png.png"> Python [Terminal Based]
Download `main.py`<br>
Type `pip install pyautogui`<br>
Open `cmd` and type `python3 main.py`
You must be in the same directory before opening the `cmd`

### <img align="center" width="30px" src="https://cdn3d.iconscout.com/3d/premium/thumb/mobile-app-3d-icon-png-download-5660920.png">.EXE Version [Executable]
Download `GhostType.exe`<br>
Run the file.
